### `office_batch_edit`

*edits the document*

Apply several edits to ONE document in a single step: the file is opened once, all
operations run in order, and it is saved once. If any operation fails, NOTHING is saved.
Much faster than separate tool calls - prefer it when making 3+ changes to a document.

Each operation is {"op": "<app>.<name>", "args": {...}} where the name and arguments match
the editing tool of the same name, e.g.
{"op": "writer.add_heading", "args": {"text": "Intro", "level": 1}}.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `path` | string | yes | Path to the document. Absolute, or relative to the default documents folder. Supports ~ for the home folder. |
| `operations` | list of object | yes |  |

### `writer_add_content`

*edits the document*

Build a whole section in ONE call: a list of blocks inserted in order. Each block has a
`type`: heading, paragraph, bullets, numbered, table, image or page_break. This is the
fastest way to write a document - prefer it over many single-paragraph calls.
Example: [{"type":"heading","text":"Report","level":1},
{"type":"paragraph","text":"Intro..."},
{"type":"table","data":[["Name","Qty"],["Apple","3"]]}]

|---|---|---|---|
| `path` | string | yes | Path to the document. Absolute, or relative to the default documents folder. Supports ~ for the home folder. |
| `blocks` | list of object | yes |  |
| `position` | `end` \| `start` \| `before` \| `after` |  | Where to insert: 'end' of the document (default), 'start', or 'before' / 'after' the block given in block_index. Default: `end`. |
| `block_index` | integer |  | Reference block index; required when position is 'before' or 'after'. |
